# Language Rules

- Write outcomes first
- Use buyer language, not internal system names
- Say "draft", "assisted", "organized", "summarized", or "reviewed" where appropriate
- Do not promise legal outcomes, approvals, wins, authorization, or certification
- Do not imply automatic delivery, automatic publishing, or automatic payment
- State required buyer input clearly
- State review and modification boundaries clearly
- Do not include real contact details, secrets, or private customer data
