# DSH 闲鱼商品层

这里存放可直接复制到闲鱼发布页的商品资料。

规则：

- 品牌统一使用 `DSH`
- 图片不放价格
- 价格只写在 `listing.md` 和 `pricing.md`
- 每个商品都必须有标题、交付物、输入、周期、修改、排除项、FAQ、话术和发布检查表
- `material-ready` 不等于已经发布，只表示物料完整
- `capability-review` 和 `hold` 必须保留人工确认边界

目录导航：

- [catalog.md](catalog.md)
- [publish-checklist.md](publish-checklist.md)
- [shared](shared/)
